Roblox Integration

GET / POST
GET
/api/movies

Returns a JSON array of all Disney movies with titles, years, and tags.

{ "movies": [ { "title": "The Lion King", "year": 1994, "tag": "Hakuna Matata" }, { "title": "Frozen", "year": 2013, "tag": "Let it go" } ] }
GET
/api/characters

Returns a JSON array of Disney characters with their associated movies.

{ "characters": [ { "name": "Simba", "icon": "fa-crown", "movie": "Lion King" }, { "name": "Elsa", "icon": "fa-gem", "movie": "Frozen" } ] }
GET / POST
/api/magic

Get current magic count or increment it (POST with { "action": "increment" }).

{ "magic": 42, "message": "✨ Magic level updated" }

Roblox Luau Example

-- Fetch Disney movies from the API local HttpService = game:GetService("HttpService") local url = "https://chrisy1011112.github.io/DIsney.inc/api/movies" local success, result = pcall(function() return HttpService:GetAsync(url) end) if success then local data = HttpService:JSONDecode(result) for _, movie in ipairs(data.movies) do print(movie.title .. " (" .. movie.year .. ")") end else warn("Failed to fetch Disney data") end

Replace the URL with your actual GitHub Pages URL when deployed.
